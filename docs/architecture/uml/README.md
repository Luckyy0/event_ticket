# Danh sách Biểu đồ UML

Thư mục này chứa các biểu đồ và mô hình được viết bằng **Mermaid** hoặc **PlantUML**. Các biểu đồ này minh họa các luồng hệ thống, chuyển đổi trạng thái, và các thành phần cấu trúc.

## Các Biểu đồ Hiện có

1. `docs/architecture/system-context.md` - Ngữ cảnh Hệ thống (Mermaid C4)
2. `docs/architecture/container-diagram.md` - Cấp độ Container (Mermaid C4)
3. `docs/architecture/authentication-flow.md` - Trình tự Xác thực (Mermaid)
4. `docs/architecture/reservation-flow.md` - Trình tự Đặt chỗ (Mermaid)
5. `docs/architecture/payment-flow.md` - Trình tự Thanh toán (Mermaid)
6. `docs/architecture/saga-flow.md` - Chuyển đổi Trạng thái / Luồng Saga (Mermaid)

*Lưu ý: Trong tương lai, các tệp `.puml` hoặc `.mmd` độc lập có thể được lưu trữ trong thư mục này cho các mô hình phức tạp.*
